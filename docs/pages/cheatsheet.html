Packathon: Command Cheat Sheet

Quick reference guide for Linux packaging, binary forensics, and dependency resolution

1. RPM Toolbox

The rpm command operates in two fundamentally different modes:

  • Uninstalled File Mode (requires -p / --package): Queries an isolated .rpm file on disk (for example, freshly compiled in dist/ocio.rpm or downloaded from GitHub). The package is not installed and the system database is never touched. Use this for pre-installation auditing: inspecting which files will be placed in /usr, checking library requirements, and reading scriptlets before letting them execute as root.
  • Installed Database Mode (queries /var/lib/rpm): Queries packages that are already installed as part of the operating system. Commands take package names (e.g. ocio, libglvnd) or real filesystem paths (-qf), not .rpm file paths. Use this for system maintenance and auditing: identifying which package owns a library, checking reverse dependencies before removal, and verifying file integrity against database digests (rpm -V).

File inspection

Identify the file type and extract contents to the local directory without database registration or root privileges:

# Identify RPM file format, architecture, and lead magic bytes
$ file ocio-0.1.0-1.x86_64.rpm

# Extract archive contents into the current directory without installing
$ rpm2cpio ocio-0.1.0-1.x86_64.rpm | cpio -idmv

RPM Query Comparison: Uninstalled File vs. System Database

Task Uninstalled (.rpm file) Installed (System DB)
Which files are inside? rpm -qlp FILE.rpm rpm -ql PACKAGE_NAME
What capabilities does it require? rpm -qp --requires FILE.rpm rpm -q --requires PACKAGE_NAME
What capabilities does it provide? rpm -qp --provides FILE.rpm rpm -q --provides PACKAGE_NAME
What scripts run as root? rpm -qp --scripts FILE.rpm rpm -q --scripts PACKAGE_NAME
Show package metadata and signature rpm -qip FILE.rpm rpm -qi PACKAGE_NAME
Who owns this file? N/A rpm -qf /path/to/file
Who needs / depends on this? N/A rpm -q --whatrequires CAPABILITY
Who provides this capability? zypper se --provides --match-exact CAP
dnf provides CAP		 rpm -q --whatprovides CAPABILITY

Integrity Verification & Safe Removal

Audit installed packages against the RPM database digests and simulate removals without modifying the system:

# Verify installed files against database digests, permissions, and timestamps
$ rpm -V ocio

# Test removal to check for broken dependencies without actually uninstalling (dry-run)
$ rpm -e --test libglvnd

2. Binary Inspection & Dynamic Linking (ld.so)

Commands used to inspect ELF executables, shared library dependencies, and loader behavior:

# Inspect dynamic shared library requirements and resolved paths
$ ldd ./ocio

# Read dynamic section tags (DT_NEEDED, RPATH, RUNPATH)
$ readelf -d ./ocio

# Filter only shared libraries required by the binary
$ readelf -d ./ocio | grep NEEDED

# Check exit status of a failed binary (e.g. 127 = dynamic linker could not find a library)
$ ./ocio; echo $?

# Check ELF architecture, ABI, and dynamic interpreter (PT_INTERP)
$ file ./ocio
Runtime vs Package: ldd inspects what the dynamic linker (ld.so) sees on the running host. rpm -qp --requires inspects what the package metadata declared at build time. When a package is properly built, the package requirements match the ELF DT_NEEDED list.

3. Archive Extraction & Payload Inspection

How to inspect and unpack package payloads without installing them to the root filesystem:

# Extract an RPM payload directly into the current directory
$ rpm2cpio ocio-0.1.0-1.x86_64.rpm | cpio -idmv

# Verify archive format of the RPM payload stream
$ rpm2cpio ocio-0.1.0-1.x86_64.rpm | file -

# Query payload format and compressor used in the RPM
$ rpm -qp --qf '%{PAYLOADFORMAT} %{PAYLOADCOMPRESSOR}\n' ocio-0.1.0-1.x86_64.rpm

# Alternative direct extraction using bsdtar (libarchive)
$ bsdtar -tf ocio-0.1.0-1.x86_64.rpm
$ bsdtar -xf ocio-0.1.0-1.x86_64.rpm

# Inspect Debian package (.deb) members (ar archive containing control.tar and data.tar)
$ ar -t ocio_0.1.0_amd64.deb
$ ar -x ocio_0.1.0_amd64.deb

4. Repository & Package Manager Operations

Commands for dependency resolution and package operations across openSUSE, Fedora, and Debian:

# openSUSE (Zypper / libsolv)
# Search repository for package providing an exact symbol or capability
$ zypper se --provides --match-exact 'libOpenGL.so.0()(64bit)'

# Query requirements of an upstream package before installation
$ zypper info --requires libglvnd

# Install local RPM resolving transitive dependencies from repos
$ sudo zypper in /path/to/ocio-0.1.0-1.x86_64.rpm

# Bypass GPG signature check for untrusted or experimental local packages
$ sudo zypper in --allow-unsigned-rpm /path/to/ocio-0.1.0-1.x86_64.rpm

# Fedora / RHEL (DNF / libdnf)
# Search repository for package providing a file or capability
$ dnf provides 'libOpenGL.so.0()(64bit)'

# Install local RPM resolving remote dependencies
$ sudo dnf install /path/to/ocio-0.1.0-1.x86_64.rpm

# Debian / Ubuntu (APT)
# Install local DEB package resolving remote dependencies
$ sudo apt-get install /path/to/ocio_0.1.0_amd64.deb

5. Container & Sandbox Testing

Commands used to test binaries, packages, and sandboxes in clean environments:

# Test raw binary in a pristine, vanilla openSUSE Tumbleweed container (fails due to missing libs)
$ podman run --rm -v ./build/bin/ocio:/ocio:ro,Z registry.opensuse.org/opensuse/tumbleweed:latest /ocio

# Test RPM package installation and execution in a pristine vanilla container
$ podman run --rm -v "$PWD/dist/ocio-0.1.0-1.x86_64.rpm:/ocio.rpm:ro,Z" \
    registry.opensuse.org/opensuse/tumbleweed:latest \
    sh -c "zypper --non-interactive in --allow-unsigned-rpm /ocio.rpm && ocio --version"

# Extract AppImage payload without FUSE (inspect internal SquashFS)
$ ./ocio-x86_64.AppImage --appimage-extract

# Build and export Flatpak bundle
$ flatpak-builder --force-clean build-dir packaging/flatpak/org.packathon.ocio.yml
$ flatpak-builder --export-bundle repo ocio.flatpak org.packathon.ocio

# Run application inside Podman with X11 and DRI GPU pass-through
$ podman run --rm -it --net=host --ipc=host \
    -e DISPLAY=$DISPLAY \
    -v /tmp/.X11-unix:/tmp/.X11-unix:ro \
    --device /dev/dri \
    localhost/packathon-opensuse:runtime
