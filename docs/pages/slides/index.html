Exploring Modern Packaging & Automated Releases

The Excuse: ocio

A lightweight single-window C application powered by raylib

  • Interactive eye tracking the mouse cursor
  • Saccadic damping motion
  • Static linking architecture with minimal dependencies

The Packaging Challenge

“After miserably failing to distribute ocio via floppy disks by postal mail, I decided to explore modern packaging.”

Different distros, different formats, different expectations.

Release Formats

Traditional Packages

  • DEB (Debian/Ubuntu)
  • RPM (Fedora/openSUSE)
  • Tarball (.tar.gz / .zip)

Sandboxed & Bundles

  • AppImage
  • Flatpak
  • Container images

Automated CI/CD Pipeline


# Native run & test
$ cmake -B build -S .
$ cmake --build build
$ ./build/src/ocio --version
ocio 0.1.0

GitHub Actions workflows compile, package, and release automatically on tag pushes.
